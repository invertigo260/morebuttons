# MoreButtons

A Quality-of-Life mod for **Lethal Company** that adds configurable hotkeys for common actions.

## Features

- **F5 - Contextual Teleport**:
  - **Inside ship**: Triggers the **Inverse Teleporter** (if present and ready).
  - **Outside ship**: Targets the local player on the ship radar and triggers the **Regular Teleporter** to beam you back up to the ship.
- **F7 - Ship Lights Toggle**:
  - Toggles the ship light switch from anywhere.

## Configuration

All keybinds are configurable via the BepInEx configuration file (`BepInEx/config/com.invertigo.morebuttons.cfg`).
